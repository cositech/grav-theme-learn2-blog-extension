# Roadmap

Geplante Features und Verbesserungen für die Learn2 Blog Extension.

## Legende

- 🎯 **Geplant** - Auf der Roadmap
- 🚧 **In Arbeit** - Wird entwickelt
- ✅ **Fertig** - Implementiert
- 💭 **Überlegt** - Wird diskutiert
- 🔥 **Priorität** - Wichtig/Dringend

---

## Version 1.1.0 (Q2 2026)

### Features

- 🎯 **Featured Posts** Support
  - Posts als "Featured" markieren
  - Separate Anzeige auf der Startseite
  - Eigenes Styling für hervorgehobene Posts
  - Badge/Label für Featured Posts

- 🎯 **Autor-Profile**
  - Avatar-Support für Autoren
  - Autor-Bio in Sidebar
  - Autor-Archiv-Seiten
  - Social Media Links für Autoren

- 🎯 **Lesezeit-Anzeige**
  - Automatische Berechnung der Lesezeit
  - Konfigurierbare Lesegeschwindigkeit
  - Icon-Anzeige in Post-Meta

- 🎯 **Related Posts**
  - Automatische Vorschläge ähnlicher Posts
  - Basierend auf Tags/Kategorien
  - Konfigurierbare Anzahl
  - Template-Partial für Wiederverwendung

### Verbesserungen

- 🎯 Dark Mode Support
- 🎯 Verbesserte Mobile-Navigation
- 🎯 Accessibility-Verbesserungen (ARIA-Labels)
- 🎯 Print-Stylesheet

---

## Version 1.2.0 (Q3 2026)

### Features

- 🎯 **Social Media Integration**
  - Share-Buttons (Twitter, Facebook, LinkedIn, etc.)
  - Open Graph Meta-Tags
  - Twitter Cards
  - Konfigurierbare Share-Optionen

- 🎯 **Blog-Widgets**
  - Sidebar-Widget für neueste Posts
  - Tag-Wolke-Widget
  - Kategorien-Widget
  - Archiv-Widget (nach Monat/Jahr)

- 🎯 **Advanced Search**
  - Volltext-Suche in Blog-Posts
  - Filter nach Tags/Kategorien
  - Datum-Range-Filter
  - Search-Results-Template

- 💭 **Newsletter-Integration**
  - Subscribe-Box in Posts
  - Integration mit populären Newsletter-Services
  - GDPR-konform

### Verbesserungen

- 🎯 Performance-Optimierungen
  - Lazy Loading für Bilder
  - CSS-Optimierung
  - Template-Caching-Verbesserungen

## Version 1.3.0 (Q4 2026)

### Features

- 💭 **Multi-Language Support**
  - Übersetzungen für UI-Elemente
  - Multi-Language Blog Posts
  - Language-Switcher
  - RTL-Support

- 💭 **Advanced Taxonomies**
  - Series/Collections Support
  - Custom Taxonomies
  - Taxonomy-Archive-Seiten
  - Taxonomy-Filter-Widget

- 💭 **Content Scheduling**
  - Geplante Veröffentlichungen
  - Auto-Publish zu bestimmten Zeiten
  - Draft/Published Status-Verwaltung

- 💭 **SEO Enhancements**
  - Structured Data (Schema.org)
  - Breadcrumb Schema
  - Article Schema
  - Automatische Meta-Description-Generierung

## Version 2.0.0 (2027)

### Breaking Changes

- 💭 Modernisiertes CSS (CSS Grid/Custom Properties)
- 💭 Grav 2.0 Kompatibilität
- 💭 PHP 8.2+ Requirement

### Major Features

- 💭 **Visual Editor Integration**
  - WYSIWYG-Editor für Posts
  - Drag & Drop Bilder
  - Live-Preview

- 💭 **Advanced Media Management**
  - Gallery-Support in Posts
  - Video-Embeds
  - Audio-Player
  - Image-Lightbox

- 💭 **Analytics Integration**
  - View-Counts für Posts
  - Popular-Posts-Widget
  - Traffic-Statistiken
  - Privacy-freundliche Analytics

- 💭 **Advanced Comment System**
  - Threaded Comments
  - Comment-Moderation
  - Spam-Protection
  - Social Login

## Wie kannst du beitragen?

### Feature-Requests

- Öffne ein [GitHub Issue](https://github.com/DEIN-USERNAME/grav-theme-learn2-blog/issues)
- Nutze das Feature-Request-Template
- Beschreibe Use-Case und Nutzen
- Diskutiere mit der Community

### Development

- Sieh dir [CONTRIBUTING.md](CONTRIBUTING.md) an
- Pick ein Issue mit `help wanted` Label
- Implementiere Features aus dieser Roadmap
- Erstelle Pull Requests

### Testing & Feedback

- Teste Beta-Versionen
- Gib Feedback zu neuen Features
- Melde Bugs
- Verbessere Dokumentation

### Sponsoring

- Nach Release: GitHub Sponsors aktivieren
- Finanzielle Unterstützung ermöglicht schnellere Entwicklung
